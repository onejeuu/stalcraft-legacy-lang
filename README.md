# STALCRAFT Legacy Lang Mod

Мод возвращает в игру [STALCRAFT](https://stalcraft.net) старую локализацию.

Для установки модификации воспользуйтесь готовым установщиком, доступным на странице [Releases](https://github.com/onejeuu/stalcraft-legacy-lang/releases/latest).

> [!IMPORTANT]
> Мод реализован только на русском языке.

## 🛡️ Безопасность

В соответствии с руководством [Допустимые изменения файлов «STALCRAFT: X»](https://support.exbo.net/ru/help-center/articles/1/37/386#mcetoc_1i0c3ck2910): изменение названий предметов, а так же "перевод" на другие языки допускается.

## 🔄 Обновление

После выхода патчей для игры файлы локализации могут обновиться. Чтобы мод продолжил работать, запустите установщик ещё раз.

Во время установки скрипт может предложить восстановить резервные копии оригинальных файлов. Выберите "Нет, продолжить установку", чтобы переустановить мод.

> [!NOTE]
> Мод заменяет только те строки, которые относятся к старой локализации. Все остальное остается неизменным.

## 🧹 Удаление

Если вы хотите удалить модификацию, просто снова запустите установщик. Скрипт автоматически обнаружит резервные копии и восстановит оригинальные файлы локализации.

> [!IMPORTANT]
> Удаление будет корректным только в том случае, если за время использования мода не выходило патчей игры. В противном случае резервная копия может оказаться устаревшей.

Резервные копии оригинальных файлов сохраняются по пути: `%USERNAME%/sclegacylang/backup`.

## 🛠️ Сборка

1. Скачайте проект

   ```bash
   git clone https://github.com/onejeuu/stalcraft-legacy-lang
   ```

   ```bash
   cd stalcraft-legacy-lang
   ```

2. Рекомендуется создать виртуальную среду

   ```bash
   python -m venv .venv
   ```

   ```bash
   .venv\Scripts\activate
   ```

3. Установите зависимости

   через poetry

   ```bash
   poetry install
   ```

   или через pip

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите скрипт для компиляции

   ```bash
   python build.py
   ```

   В каталоге `/dist` будет создан исполняемый файл `stalcraft-legacy-lang.exe`
